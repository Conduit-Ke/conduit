# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-01-14

### Added
- Initial release of the SMS Routing Enterprise Gateway Edge Node.
- AES-256-CBC end-to-end encryption for SMS content.
- Multi-SIM support with health monitoring and quarantine logic.
- Automated release pipeline with GitHub Actions.
- Comprehensive security stack including HMAC-SHA256 signing and AES-GCM control channel encryption.
- Performance-optimized storage using SQLCipher.
- Real-time telemetry and health-check heartbeats.
- Device-side rule evaluation engine.
